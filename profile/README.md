<p>企业里给多台电脑分地址，先要想清楚谁能访问什么，再决定地址怎么给。本文按分段、划 VLAN、配多出口策略路由、按部门下发策略、划清权限边界、上线巡检的顺序讲。</p>
<h2>一、先分段，再分地址</h2>
<p>几十台电脑挤在一个网段里，广播多、排查难、权限也没法区分。先按用途分段，地址分配才有依据。</p>
<p>常见分法是办公、研发、财务、访客、服务器各成一段。段与段之间默认不通，需要的再单独放行。</p>
<p>分段不是越细越好。段太多，策略规则成倍增加，维护成本反而高。按部门加敏感度分，一般五到八段够用。</p>

<h2>二、VLAN 和网段怎么划</h2>
<p>一个 VLAN 对应一个网段，这是最省心的做法。一个 VLAN 塞多个网段也能跑，但排查时容易绕晕。</p>
<p>网段编号和 VLAN 号对齐，比如 VLAN 20 用 10.10.20.0，看地址就知道在哪个段，不用查表。</p>
<p>三层交换机或路由器上做网关，每个 VLAN 一个网关地址。网关地址统一用段内第一个可用地址，形成习惯。</p>
<h3>访客段一定要隔离</h3>
<p>访客段只放行出网，禁止访问内网任何段。访客设备不可控，一个带毒笔记本就能横向扫描整个内网。</p>
<h2>三、多出口时怎么选路</h2>
<p>有两条以上线路时，默认路由只有一条。要让不同网段走不同出口，靠策略路由，按源地址匹配。</p>
<p>策略路由的规则要写具体：源网段、目的、出口、优先级。规则越笼统，越容易互相覆盖，最后不知道走哪条。</p>
<p>出口切换要考虑回程。去和回走不同线路会产生非对称路由，表现为能通但慢、或者大包不通。</p>
<h2>四、按部门下发不同策略</h2>
<p>财务和研发的访问需求不同。财务只放行必要的业务系统，研发需要访问代码仓库和测试环境，策略分开写。</p>
<p>带宽也能按段限。给访客段限速，避免下载把整条线路占满，办公段的体验立刻改善。</p>
<p>策略写在防火墙上而不是终端上。终端上的限制用户能改，网络侧的限制才真正生效。</p>
<h3>默认拒绝比默认放行安全</h3>
<p>段间策略默认拒绝，需要什么开什么。默认放行再逐条封禁，早晚会漏掉一条，而且很难发现。</p>
<h2>五、地址和权限的边界</h2>
<p>公网地址只给必须被外部访问的设备，比如对外站点、VPN 入口、邮件网关。办公终端一律走 NAT。</p>
<p>需要固定出口的业务，单独划一个段并绑定出口地址，不要让整个办公段跟着走，影响面太大。</p>
<p>权限跟地址走，不跟人走。人换了，权限留在原地，交接时按地址核对一遍，比按人核对可靠。</p>

<h2>六、上线后怎么巡检</h2>
<p>每周看一次地址表，核对在线设备和台账是否一致。对不上的先标记，别急着改，可能是临时接入。</p>
<p>每月看一次策略命中计数。长期零命中的规则可以清理，规则越少，出问题时越容易定位。</p>
<p>每季度做一次出口切换演练。真断线时才发现备用线路没配好，这类事故很常见，演练能提前暴露。</p>

<h2>常见问答</h2>
<h3>企业里每台电脑都要公网 IP 吗？</h3>
<p>答：不需要。只有必须被外部主动访问的设备才需要，普通办公终端通过 NAT 出网即可，管理更简单也更安全。</p>
<h3>分段以后电脑之间不能互访怎么办？</h3>
<p>答：在防火墙上按需放行，比如允许办公段访问服务器段的特定端口。默认拒绝加白名单，比整段互通安全。</p>
<h3>策略路由会影响上网速度吗？</h3>
<p>答：规则数量少时影响可以忽略。规则过多或匹配顺序混乱时会增加转发延迟，建议定期清理无效规则。</p>
<h3>访客网络怎么设比较稳妥？</h3>
<p>答：单独 VLAN、单独网段、只放行出网，禁止访问内网任何地址，并按端口限速。这样既可用，也不会成为内网入口。</p>
